## 🎯 Назначение и ключевые возможности

Комплекс **«Морзе-М» (Р-010-УМ)** объединяет в одном автономном веб-интерфейсе генератор учебных радиограмм, имитатор реального КВ-эфира с помеховой обстановкой, эмулятор аппаратных манипуляторов и систему объективного контроля с дифференциальной автопроверкой.

- **Генерация радиограмм:** Буквенные, цифровые и смешанные радиограммы стандартными 5-значными группами (с возможностью деления на группы по 2–4 знака) с поддержкой приоритетного веса (увеличение частоты выпадения трудных символов в 3 раза).
- **Слуховой приём (RX):** Воспроизведение по стандарту PARIS с поддержкой раздельной регулировки скорости напева, межбуквенного интервала и межгрупповой паузы на лету.
- **Передача (TX):**
  - _Вертикальный (ручной) ключ:_ с адаптивным распознаванием индивидуального почерка курсанта (АРУ темпа руки на базе EMA-фильтра).
  - _Электронный ключ (Iambic Mode B):_ с памятью элементов, автоматическим чередованием и ямбическим сжатием.
- **Аппаратная эмуляция без внешнего оборудования:** Полноценная работа с клавиатуры (включая русскую раскладку) или манипулятора «мышь» (ЛКМ — точка, ПКМ — тире).
- **DSP-симулятор эфира:** Моделирование шума эфира (QRN), мешающих радиостанций (QRM), глубоких замираний (QSB) и регулируемых фронтов посылки (Anti-Click).
- **Визуальный ондулятор:** Виртуальный самописец на бегущей бумажной ленте в реальном времени с субпиксельной отрисовкой и селектором каналов (TX / RX / сквозной).
- **Объективный контроль:** Математическое выравнивание принятого текста относительно эталона без эффекта «лавинного сдвига» при пропуске символа.

---

В `Морзе-М.html` реализован комплекс инженерных решений для безотказной работы на закрытых АРМ и спецтерминалах:

1. **Защита от сбоев в Parsec MAC при открытии через `file://`:**
   - В защищённых дистрибутивах (Astra Linux 1.5 / 1.6) при строгих мандатных атрибутах вызов `new Worker(blobUrl)` из локального файла может блокироваться политиками безопасности (`SecurityError`).
   - В Astra Edition фоновый Web Worker обёрнут в безопасный контейнер с автоматическим переключением на высокоточный fallback-таймер `safeSleep`. Приложение гарантированно стартует в любых профилях безопасности.
2. **Поддержка двуязычной передачи (RU / EN):**
   - Курсанту больше **не требуется переключать системную раскладку**: ямбический ключ перехватывает как латинские `Z` / `X`, так и русские клавиши **`Я`** (точка) и **`Ч`** (тире).
   - Поля ввода текста и списки защищены от случайного перехвата горячих клавиш телеграфа.
3. **Трехфакторная модель скоростных нормативов:**
   - Вместо зависимого расчёта Фарнсворта внедрены **3 независимых шкалы**:
     1. _Скорость напева:_ $30 \dots 180$ знаков/мин (формирует длину элементарной точки $\tau$);
     2. _Межбуквенная пауза:_ от нормативных $3\,\tau$ до расширенных $20\,\tau$ (с индикацией кратности и времени в миллисекундах);
     3. _Межгрупповая пауза:_ от нормативных $7\,\tau$ до $60\,\tau$ (с индикацией кратности и времени в секундах).
4. **Аппаратная оптимизация «Приёма вслепую» (Blind Mode):**
   - Отказ от тяжёлого шейдерного фильтра `filter: blur(7px)`, вызывающего просадку FPS на встроенных видеоадаптерах и программном рендере в Astra Linux.
   - Знаки радиограммы маскируются в тактовые символы-заполнители (`•`), а курсор подсвечивает текущий принимаемый знак в реальном времени (`■`), позволяя курсанту ориентироваться в темпе приёма без подсказки букв.
5. **Совместимость с графической подсистемой Fly UI:**
   - Стилизованные выпадающие списки `<select>` переведены на безопасный inline-SVG маркер и изолированные цвета выпадающих меню, предотвращающие системный баг белого текста на белом фоне в темах Astra Linux.
   - Полифилы `NodeList.forEach` и `Element.closest` написаны на чистом ES5 без сторонних зависимостей.
6. **Акустический компрессор/лимитер тракта:**
   - В звуковой тракт встроен узел `DynamicsCompressor` с мягким коленом, предотвращающий клиппинг и перегрузку наушников оператора при одновременном наложении тона, замираний (QSB) и статических разрядов грозового фронта (QRN).

## 🏗 Архитектура и технические решения

- **Zero-Dependency (100% монолит):** Каждый вариант тренажёра представляет собой один самостоятельный `.html`-файл размером менее **100 КБ**. Не требует Node.js, веб-серверов, баз данных или сторонних библиотек.
- **Модульная разработка → монолитная поставка:** исходники разделены по функциональным модулям в папке `src/`, а на флешку попадает один собранный файл. Ни Webpack, ни `node_modules` не используются — достаточно Python 3 из состава ОС (см. «🧩 Сборка изделия из модулей»).
- **Изолированный тайминг (Anti-Throttling Web Worker):** Чтобы фоновые вкладки браузера не искажали тактовую сетку телеграфа из-за троттлинга таймеров операционной системой, генерация тактов вынесена в фоновый поток Web Worker (с отказоустойчивым резервированием).
- **Web Audio API Native Synthesis:** Синтез телеграфного тона, фильтрация ПЧ/НЧ, формирование фронтов и модуляция шума выполняются в реальном времени аппаратным графом Web Audio без использования предзаписанных аудиофайлов.

### 🧩 Сборка изделия из модулей

Поставка **обязана** оставаться единым `.html`-файлом: на флешке в изолированном классе нельзя рассчитывать ни на корректно смонтированные относительные пути, ни на разрешение политики безопасности для `file://`, ни на поднятый веб-сервер. Разработка при этом ведётся по модулям, а сборка выполняется отдельным скриптом на стандартной библиотеке Python.

```text
MORZE-M/
├── build.py                     # сборщик: склеивает src/ в один .html (только os/re/sys/time)
├── src/
│   ├── index.html               # шаблон: разметка интерфейса + метки включения
│   ├── css/
│   │   └── style.css            # все стили
│   └── js/
│       ├── polyfills.js         # совместимость Gecko 43, DOM-хелперы, ввод Ø, Worker-таймер
│       ├── morse-db.js          # таблица знаков, напевы, словари, чистка текста
│       ├── audio.js             # Web Audio: тон, QSB/QRM/QRN, фронты, компрессор
│       ├── undulator.js         # самописец ленты на Canvas 2D
│       ├── rx-trainer.js        # приём на слух, нормировка пауз, контроль радиограмм
│       ├── tx-keyer.js          # прямой ключ и Iambic Mode B, клавиатура и мышь
│       └── app.js               # вкладки, таблица кодов, слайдеры, часы, старт
└── build/                       # ГОТОВЫЕ ФАЙЛЫ ПОСТАВКИ (собираются автоматически,
    ├── Морзе-М.html             #   в git не хранятся, см. .gitignore)
    └── Морзе-М.min.html
```

**Порядок работы:**

1. Внести правку в нужный модуль `src/` (например, логику ключа — в `src/js/tx-keyer.js`, стили — в `src/css/style.css`).
2. Пересобрать поставку:

```bash
python3 build.py
```

3. Скопировать файл `build/Морзе-М.html` на флешку и открыть его двойным кликом на целевом компьютере.

**Режим наблюдения (для локальной разработки):** чтобы не запускать сборку вручную после каждого сохранения в редакторе, добавьте ключ `--watch` — сборщик сам пересобирает монолит при изменении любого файла в `src/` (остановка — `Ctrl+C`):

```bash
python3 build.py --watch
```

**Минифицированная сборка (для слабых машин):** ключ `--minify` (синоним `--release`) дополнительно вырезает лишние пробелы и переводы строк и складывает результат в отдельный файл `build/Морзе-М.min.html`. Синтаксис при этом не меняется — только ES5, файл запускается на Firefox 38 / Gecko 43 так же, как обычная сборка:

```bash
python3 build.py --minify
```

Сборка занимает доли секунды: скрипт `build.py` подставляет содержимое файлов вместо меток включения вида `/* @include путь */` в шаблоне `src/index.html`. Все модули попадают внутрь **одного** тега `<script>`, поэтому образуют общее глобальное пространство имён: объявления `function` видны между модулями, а порядок включения важен только для кода, выполняемого сразу при загрузке.

**Правила совместимости (Gecko 43 / Astra Linux 1.6–1.7):**

- Только ES5: `var`, `function`, циклы `for`. Запрещены `import`/`export`, стрелочные функции, `async`/`await`, spread `{...obj}`, шаблонные строки, `class`, `Array.prototype.includes`, `Object.assign/values/entries`.
- Web Worker создаётся **только** из `Blob` + `URL.createObjectURL` — внешний файл worker'а с `file://` блокируется политикой same-origin.
- Только `ScriptProcessorNode` / `createOscillator()` / `createBufferSource()`: `AudioWorklet` в Gecko 43 отсутствует.
- Метки включения в `src/index.html` пишутся с колонки 0: отступ перед ниной попадёт в первую строку внедряемого кода.
- Файлы в папке `build/` генерируются скриптом — правки вносить только в `src/` и не забывать пересборку.

### 📐 Математические модели и алгоритмы

#### 1. Расчёт базовых интервалов (Стандарт PARIS)
За эталон принята длительность передачи контрольного слова `PARIS`, эквивалентная **50 элементарным посылкам** ($\tau$). При скорости $V$ знаков в минуту:

$$\tau = T_{\text{dot}} = \frac{60\,000}{V \times 50 / 5} = \frac{6000}{V}\text{ (мс)}$$

- Длительность точки: $T_{\text{dot}} = 1 \times \tau$
- Длительность тире: $T_{\text{dash}} = 3 \times \tau$
- Пауза между элементами знака: $T_{\text{elem}} = 1 \times \tau$

---

#### 2. Модель нормирования скорости и пауз

- **В стандартной редакции (Farnsworth Timing):**  
  Интервалы масштабируются через интервальную скорость $V_{\text{farn}} \le V_{\text{char}}$:

$$\tau_{\text{farn}} = \frac{6000}{V_{\text{farn}}}$$

$$T_{\text{char}} = \max\left(0,\, 3 \times \tau_{\text{farn}} - \tau\right), \quad T_{\text{group}} = \max\left(0,\, 7 \times \tau_{\text{farn}} - \tau\right)$$

- **В редакции Astra Edition (3 независимых регулятора):**  
  Инструктор напрямую задаёт множители интервалов в тактах $\tau$:

$$T_{\text{char}} = (K_{\text{char}} - 1) \times \tau, \quad K_{\text{char}} \in [3 \dots 20]\,\tau$$

$$T_{\text{group}} = (K_{\text{group}} - 1) \times \tau, \quad K_{\text{group}} \in [7 \dots 60]\,\tau$$

*(Вычитание $1\,\tau$ компенсирует обязательный межэлементный такт тишины после завершения последнего элемента знака).*

---

#### 3. Проверка радиограмм без сдвига (Needleman — Wunsch)
Для объективного контроля приёма используется алгоритм глобального выравнивания последовательностей. Матрица штрафов формируется динамически:

$$D(i, j) = \min \begin{cases} 
D(i-1, j) + 1 & \text{(пропуск знака в принятом тексте)} \\
D(i, j-1) + 1 & \text{(лишний фантомный знак)} \\
D(i-1, j-1) + \text{cost} & \text{(совпадение: cost = 0; искажение: cost = 1)}
\end{cases}$$

Алгоритм точно выявляет локальные ошибки курсантов (`_[О]` — пропуск, `П[+]` — вставка, `А[Т]` — замена), не разрушая сопоставление оставшейся части радиограммы.

---

#### 4. АРУ ручного манипулятора (EMA-фильтр)
Длительность рабочей точки курсанта $\tau_{\text{est}}$ динамически адаптируется под индивидуальный темп кисти с помощью экспоненциального скользящего среднего:

$$\tau_{\text{est}}^{(k)} = \tau_{\text{est}}^{(k-1)} \times (1 - \alpha) + X \times \alpha, \quad \alpha = 0.28$$

где $X = \text{duration}$ для точек и $X = \frac{\text{duration}}{3}$ для тире.  
Порог разделения элементов:

$$\text{Threshold} = 1.85 \times \tau_{\text{est}}$$

---

#### 5. Цифровая обработка сигнала (DSP)
- **Anti-Clicking (Огибающая посылки):**  
  Сглаживание фронтов по закону RC-интегратора с постоянной времени $\tau_{\text{ramp}} = 3 \dots 25\text{ мс}$:

$$A(t) = 1 - e^{-t / \tau_{\text{ramp}}}$$

- **Шум эфира (QRN):**  
  Генератор розового шума на базе 3-полюсного фильтра Келлета со спадом $-3\text{ дБ/окт}$, селективным полосовым фильтром тракта ПЧ и стохастическим формирователем грозовых импульсов.
- **Замирания (QSB):**  
  Субнизкочастотный синусоидальный генератор LFO ($0.008 \dots 0.67\text{ Гц}$) с регулируемой глубиной модуляции сигнала.
- **Динамический компрессор (Astra Edition):**  
  Лимитирование пиков сигнала при совместном воспроизведении тона и помех: порог $-14\text{ дБ}$, компрессия $8:1$, атака $3\text{ мс}$, спад $60\text{ мс}$.

## 🎛 Режимы работы и сценарии применения

### Сценарий 1: Контрольный приём на слух и аттестация

1. Вкладка **«1. Приём на слух»** $\rightarrow$ выбрать нормативный профиль (например, «★ Полный алфавит»).
2. Задать размер группы (**5 знаков**) и число групп (например, **10** или **12**).
3. Включить режим скрытия радиограммы:
   - В Astra Edition: кнопка **«Скрыть знаки (Приём вслепую)»** (активируется контурная подсветка тактов без отображения символов);
   - В базовой версии: кнопка **«Скрыть от оператора»** (размытие бланка).
4. Нажать **«ПУСК ПРИЁМА»**. По окончании курсант вводит текст в поле журнала и нажимает **«КОНТРОЛЬ»**.
5. Передачу можно прервать в любой момент кнопкой **«СТОП»**: она превращается в **«▶ ПРОДОЛЖИТЬ»** и возвращает передачу ровно с места останова (прерванный тон проигрывается заново). Строка статуса показывает текущий этап; на паузе она подсвечивается красным, бланк остаётся заблокированным, а ползунки скоростей — доступными. **«ПУСК ПРИЁМА»** на паузе превращается в **«СБРОС»**: завершение приёма и разблокировка панели управления (журнал и подсветка сохраняются для сверки).
5. Программа строит карту расхождений и выставляет оценку:
   - До 1 ошибки — **«ОТЛИЧНО (5)»**
   - 2–3 ошибки — **«ХОРОШО (4)»**
   - 4–5 ошибок — **«УДОВЛЕТВОРИТЕЛЬНО (3)»**
   - Более 5 ошибок — **«НЕУДОВЛЕТВОРИТЕЛЬНО (2)»**

### Сценарий 2: Обучение с нуля (Слуховой образ + Напев)

1. Вкладка **«3. Таблица кодов»**.
2. При нажатии на карточку символа запускается контрольное звучание.
3. В карточке отображается буквенный символ, код Морзе и армейский напев (например: `Г` $\rightarrow$ `--.` $\rightarrow$ `гаа-раа-жи`).

### Сценарий 3: Передача без физического ключа

1. Вкладка **«2. Работа на ключе»**.
2. **Вертикальный манипулятор:** клавиша `Пробел` или экранная кнопка. Скорость руки вычисляется блоком АРУ автоматически.
3. **Электронный манипулятор (Iambic Mode B):**
   - Управление с клавиатуры: клавиши `Z` / `X` (в Astra Edition также русские `Я` / `Ч`);
   - Управление мышью: тачпад-зона (ЛКМ — точка, ПКМ — тире). Зажатие двух кнопок формирует автоматическое чередование `.-.-`.

### Сценарий 4: Работа в условиях сложной помеховой обстановки

1. Активировать тумблер **«Имитация реального эфира КВ (QRN/QRM/QSB)»**.
2. Во вкладке **«4. Тракт ПЧ/НЧ, QSB и Фронты»** настроить уровень атмосферного треска, замираний и мешающей соседней радиостанции.
